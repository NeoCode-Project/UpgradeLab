# UpgradeLab Online V32 — Price Engine

Изменения:

- отдельный `price-engine.js`;
- секреты Skinport не хранятся во фронтенде;
- опциональный Cloudflare Worker в папке `cloudflare-worker`;
- кэш массовых цен на 24 часа;
- Steam Market проверяется для видимых карточек;
- минимальная резервная оценка ножей снижена до $45, перчаток — до $30;
- реальные дешёвые цены больше не отбрасываются жёсткими порогами;
- кейсы разделены на обычные, редкие, сувенирные, капсулы и подарочные наборы.

## Без Worker

Сайт продолжит работать на умной резервной оценке и попытается загрузить Steam Market для видимых предметов.

## С Worker

Разверните содержимое `cloudflare-worker`, добавьте секреты в Cloudflare и направьте `/api/prices` на Worker. Не вставляйте Client Secret в `app.js`.
