# UpgradeLab Online V33 — реальные цены без ограничений

- Любая положительная цена от рынка принимается без искусственного минимума или максимума.
- Резервная оценка используется только когда ни один рынок не ответил.
- Видимые карточки сначала запрашивают `/api/steam-price` через Cloudflare Worker.
- В каталоге показывается источник: `Steam Market — реальная цена` либо `резервная оценка — рынок не ответил`.
- Кэш Steam: 12 часов. Массовый кэш: 24 часа.

## Почему кейс может стоить 9 грн

Это не обязательно ошибка: дешёвые массовые кейсы действительно могут иметь очень низкую рыночную цену. V33 не подменяет такую цену более высокой резервной оценкой.

## Как включить реальные цены

1. Разверните папку `cloudflare-worker` как отдельный Worker.
2. Привяжите маршрут Worker к домену сайта для `/api/steam-price*` и `/api/prices*`, либо настройте проксирование этих путей.
3. Для Steam-проверки секреты не нужны.
4. Для массового Skinport `/api/prices` добавьте Worker secrets `SKINPORT_CLIENT_ID` и `SKINPORT_CLIENT_SECRET`, если ваш доступ их требует.

Без Worker браузер попытается использовать публичные прокси, но они нестабильны; тогда часть карточек останется на резервной оценке.
