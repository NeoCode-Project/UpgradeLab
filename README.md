# UpgradeLab Online V16 Stable

Исправления:
- поле ставки больше не перерисовывается после каждого символа; можно сразу ввести 100, 1000 и т.д.;
- выбор одного или нескольких предметов из инвентаря работает по устойчивому уникальному ключу;
- поддержаны старые предметы без uid;
- продажа и списание предметов используют ту же устойчивую идентификацию;
- кнопка «Применить» обновляется без полной перерисовки модального окна.

Для Cloudflare Pages с Output directory `.` замените файлы в корне. Папка public не обязательна.

## V17 fixes
- Результат больше не сбрасывает колесо сразу в 0%.
- После победы/поражения сохраняются ставка, цель, шанс и сектор до нажатия «Новый апгрейд».
- Использованные предметы при этом уже безопасно списаны из инвентаря и не могут примениться повторно.
- Несколько предметов в ставке отображаются аккуратной сеткой и не накладываются друг на друга.
