# UpgradeLab Online V20

Исправления:
- собственный шанс от 0,01% до 80%; можно вводить 75, 60, 35 и другие значения;
- возвращены четыре темы оформления;
- блок ставки со скинами и доплатой больше не обрезается;
- цена и источник цены в каталоге больше не перекрываются кнопкой `+`;
- кнопки инвентаря выровнены и не перекрывают цену;
- сохранены смешанные ставки: скины + виртуальный баланс.

Для Cloudflare Pages с каталогом `.` замените `index.html`, `app.js`, `styles.css`.
