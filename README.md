# UpgradeLab Online V31 — ByMykel Categories

Изменения:
- категории берутся строго из отдельных файлов ByMykel API;
- оружие, кейсы, наклейки, граффити, агенты и брелоки больше не классифицируются по словам в названии;
- предмет из skins.json всегда остаётся оружием/ножом/перчатками, даже если в названии есть Case, Crate или Souvenir;
- предмет из crates.json всегда остаётся в разделе кейсов и капсул;
- добавлены дополнительные попытки получить публичную цену Steam Market;
- если рыночная цена недоступна из браузера, показывается честная резервная оценка.

Для Cloudflare Pages с Output directory `.` замените index.html, app.js и styles.css в корне репозитория.
