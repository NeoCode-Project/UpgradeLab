# UpgradeLab Online V35 — Working Prices

- Каталог ByMykel загружается независимо от цен.
- Оружие берётся из `skins_not_grouped.json`, поэтому market_hash_name точно совпадает с рынком, включая StatTrak™, Souvenir и состояние.
- Основной источник цен: Market.CSGO (USD). Резервный источник на сервере: Skinport sales history.
- Для видимых карточек используется Steam Market как дополнительная проверка.
- Выдуманные цены отключены. Если цена отсутствует, карточка остаётся в каталоге с надписью «Цена недоступна», но выбрать её для апгрейда нельзя.
- Для Cloudflare Pages загружайте весь корень проекта. `_worker.js` должен находиться в корне публикации.

После публикации нажмите Ctrl+F5.
