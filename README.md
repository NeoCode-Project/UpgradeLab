- виртуальный баланс можно добавлять к выбранным скинам как доплату;
- кнопка «Весь баланс» подставляет весь доступный остаток;
- ножи и перчатки определяются по названию, даже если API прислал неверную категорию;
- резервная цена ножа больше не может быть несколько гривен;
- кнопки карточек больше не перекрывают цену и источник цены;
- кнопки «Поставить» и «Продать» выровнены.
