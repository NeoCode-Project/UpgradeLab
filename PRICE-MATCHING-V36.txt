V36 — строгие цены

1. Используется только Market.CSGO prices/USD.json. RUB и автоматическая конвертация источников не смешиваются.
2. Цена сопоставляется только по полному market_hash_name.
3. Factory New / Field-Tested / StatTrak™ / Souvenir считаются разными предметами.
4. Если точного совпадения нет, отображается «Цена недоступна». Steam проверяется отдельно только для точного имени.
5. Старые кэши V35 не используются. После публикации нажмите Ctrl+F5.
