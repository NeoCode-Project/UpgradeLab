UpgradeLab Online V63 — Sandbox & Promo Update

Добавлено:
- Обычный режим и песочница с раздельными балансом, инвентарём, историей и избранным.
- В песочнице можно включить бесконечные деньги или задать тестовый баланс.
- Ручное пополнение отключено в обычном режиме.
- Промокоды работают только в обычном режиме.
- Награды промокода: деньги, XP, уровни и предметы (массив items в Firestore).
- Админ-панель создания промокодов для profile.role = "admin".
- Обновлены Firestore Rules.

ВАЖНО:
1. Разверни новые firestore.rules.
2. Роль admin назначается вручную через Firebase Console в profiles/UID поле role = "admin".
3. Не пытайся назначить role из клиента — правила это запрещают.
4. Для надёжной публичной версии выдачу наград лучше перенести в Cloud Function. Текущая версия подходит для тестового проекта, но клиентские транзакции нельзя считать полной защитой от читов.
