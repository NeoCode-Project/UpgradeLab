UpgradeLab Online V63.3 — Promo Rules Fix

Исправлена причина ошибки permission-denied при активации промокода.

ВАЖНО:
1. На GitHub Pages файлы сайта менять не обязательно, если уже установлена V63.2.
2. В Firebase Console открой Firestore Database -> Rules.
3. Полностью замени правила содержимым файла firestore.rules.
4. Нажми Publish / Опубликовать и дождись подтверждения.
5. Обнови сайт через Ctrl+F5.
